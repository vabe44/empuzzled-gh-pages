How the summon simulator works

Every portal page reads its weighted outcomes and hero pool from the same data snapshot used by Empuzzled’s summon tools. The simulator chooses an outcome first, then selects a hero from that outcome’s eligible pool.

Special rules are shown when the source data defines them, including featured pools, mystery bonuses, conditional legendary bonuses, additional draws, rotating lineups, and Instant Power grades.

Portal banners are loaded from the Empuzzled CDN. This directory and its detail pages are statically generated for search engines and GitHub Pages.
